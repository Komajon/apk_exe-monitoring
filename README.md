# AP_Babilon-T Monitor

Интерфейс — один HTML (`ui/index.html`). Две оболочки:
- **ПК (Windows)** — `desktop/`, Electron. Chromium встроен в exe, **WebView2 и .NET не нужны**. Один portable-файл, установка не требуется.
- **Android** — `src-tauri/`, Tauri.

## Сборка на GitHub
1. Создайте репозиторий, залейте все файлы (включая `.github`).
2. **Actions → Build … → Run workflow** (или просто push).
3. Артефакты: `AP_Babilon-T_Monitor_Windows` (exe) и `AP_Babilon-T_Monitor_Android` (apk). При теге `v1.0.0` файлы попадут в **Releases**.

## Windows
- Пинг настоящий ICMP через системный `ping.exe`, права администратора не нужны. Онлайн = в ответе есть `TTL=`.
- `hosts.json` положите **рядом с exe** — база загрузится при старте (формат как раньше). Если файла нет, берётся сохранённая локальная база. Файл из корня репозитория автоматически кладётся в артефакт рядом с exe.
- Экспорт JSON/CSV — обычное сохранение файла через диалог.
- Первый запуск portable-версии занимает несколько секунд (распаковка), размер exe около 80 МБ.
- Нужна Windows 10 или новее, 64-bit.
- Локальная проверка: `cd desktop && npm install && npm start`.

## Android (.apk)
- Пинг: ICMP через сокет без root; если система его не даёт — запасной TCP-тест (порты 80/443/22/8080).
- `hosts.json` из корня репозитория встраивается в apk при сборке. Импорт файла работает кнопкой «Импорт».
- Экспорт JSON/CSV на Android копирует данные в буфер обмена.
- Автопроверка работает, пока приложение открыто на экране.
- Подпись: по умолчанию ключ создаётся заново при каждой сборке, поэтому обновить поверх старой версии нельзя. Чтобы обновлялось, добавьте секреты репозитория `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` (пароль ключа = пароль хранилища).
